This repo is for the first coursework for the Programming for Cybersecurity module.
The tools in this repo are split into branches of their own.
- security-tool, variety of various simple tools, such as event counters, brute-force simulations and basic login authentication.
- security-event-logger, script which produces a typical log entry for a login attempt.
- ip-address-validator, short program which checks if an IP address fits the standard format for an IPv4 address.
- security-incident-manager, showcase of pythons ability to declare, add, remove and edit fields of a dictionary with values linked to keys.
- cyber-security-utilities
